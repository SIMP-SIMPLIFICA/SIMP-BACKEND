# 🛠️ Development Notes & Technical Debt (Simplifica Backend)
**Date:** 2026-01-24
**Context:** Initial environment setup, hotfixes for Windows/WSL, and local development bypasses.

This document records temporary changes, workarounds, and attention points for this specific commit state.

## ⚠️ Critical Changes (Hotfixes)

### 1. Email Verification Bypassed (Localhost)
To allow local development without a configured SMTP server (SendGrid/MailHog), the email verification step was bypassed.
- **File:** `src/services/auth.service.ts` (Method: `register`)
- **Action Taken:** The block `await emailService.sendVerificationEmail(...)` was commented out.
- **Future Action:** Uncomment this block before deploying to Production and ensure `SMTP_` variables in `.env` are correct.

### 2. TypeScript "Strict Mode" Relaxed
Due to type conflicts with external libraries (`fastify-jwt`) and the `request.user` object decoration:
- **File:** `tsconfig.json`
- **Action Taken:** Rules like `noImplicitAny` and `strict` were relaxed or disabled.
- **File:** `src/types/fastify.d.ts` was created to force typing of `user` as `any` to prevent build blockers.
- **Future Action:** Refactor FastifyRequest interfaces to properly type the user object and re-enable `strict: true`.

### 3. Network Binding (IPv4 vs IPv6)
In Windows/WSL environments, Node.js v17+ defaults to IPv6 (`::1`), causing connection errors with Swagger and external tools.
- **File:** `src/index.ts`
- **Action Taken:** Server forced to listen on `0.0.0.0` instead of `localhost`.
- **Future Action:** Maintain this setting as it ensures compatibility with Docker containers and WSL networking.

## 🧪 Testing Structure

### `src/test` vs `tests`
- **`src/test/`**: Contains test utilities, mocks, and in-memory database setup.
- **`tests/`**: Contains the actual Unit and E2E test specifications (`.spec.ts`).
- **Running Tests:** Use `npm run test` to execute the full suite.

## 🔐 Password Requirements (Zod)
The current validation schema enforces:
- At least 1 uppercase letter
- At least 1 lowercase letter
- At least 1 number
- At least 1 special character (`@`, `!`, etc.)
- **Valid Example:** `Test@1234`
